## API Reference
- [Merchandise Process](https://docs.spyne.ai/reference/merchandise-process.md)
- [Retrieve Media](https://docs.spyne.ai/reference/get-media.md)
- [Classify Images](https://docs.spyne.ai/reference/autoclassification.md): This API can be used to classify and validate the car images on certain parameters
- [Transform Images](https://docs.spyne.ai/reference/autotransformation.md): This page will help you get started with our replace background API for the Automobile category
- [Webhook Push Service](https://docs.spyne.ai/reference/webhook.md)
- [GET Images](https://docs.spyne.ai/reference/getreadyimages.md): This API is used to obtain all the images which are ready after processing by Spyne
- [Video Validation](https://docs.spyne.ai/reference/post_360-v1-validate-video-1.md): Accepts a video, checks the video on multiple parameters like Cropping, Angle, Car Present & returns the response accordingly!
- [Webhook Service - 360](https://docs.spyne.ai/reference/webhook-push-service-copy.md)
- [3D 360-Spin](https://docs.spyne.ai/reference/post_360-v1-3d-1.md): Accepts a publicly accessible complete-round video of vehicle and returns the smoothest ever Studio 360-spin you will ever see! Takes an hour to process but it's worth the wait. Recommended for unstable video inputs.
- [Response 360-Spin](https://docs.spyne.ai/reference/get_response.md): Fetch a response for 360 spin images or related data by either SKU name or SKU ID. Only one of them should be provided.
- [Video Generation](https://docs.spyne.ai/reference/video-generation.md)
- [Response Videos](https://docs.spyne.ai/reference/response-videos.md)
